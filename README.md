# QCTI website

Static site for qcti.digital, hosted on GitHub Pages.

- Text lives in `build.py` (Spanish and English). Edit there, then run `python3 build.py` to regenerate `index.html` and `en/index.html`.
- Styles: `assets/site.css`. Images: `assets/img/`.
- Contact form: Google Form "Contacto QCTI" (responses go to the "Contacto QCTI (Respuestas)" sheet).
